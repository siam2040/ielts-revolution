# IELTS Revolution

An IELTS learning platform built with Next.js and TypeScript.

> Status: currently in development.

## Tech stack

- Next.js
- TypeScript

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## About

IELTS Revolution is Siam Hossain's IELTS learning platform project, currently in development. Features and learning modules will be documented here as they are built.
